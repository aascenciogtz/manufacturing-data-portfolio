# Día 1 — Fundamentos SQL

## SELECT
Sirve para mostrar las columnas que quiero consultar en toda la tabla a manejar.

## FROM
Indica de qué tabla se obtienen los datos.

## LIMIT
Limita la cantidad de registros que muestran.

## AS
Permite asignar un alias a una columna o tabla para mostrar de manera más fácil la información.
