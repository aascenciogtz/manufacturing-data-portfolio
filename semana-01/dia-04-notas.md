# Notas Día 4 - Comparación de WHERE & HAVING

## WHERE
El comando WHERE se utiliza para filtrar los datos por renglones individuales antes de procesar o agrupar los datos. Este filtro funciona con datos raw y desagrupados. No se pueden utilizar los comandos COUNT(), AVG(), SUM(), etc., para su funcionamiento.

## HAVING
Este comando filtra los grupos que se indiquen una vez que se hayan procesado y agrupado los datos, o se haya ejecutado alguna operación como tal para los datos que se están tratando. Se utiliza principalmente para funciones agregadas y permite filtrar por grupos con los datos procesados.
