# Manufacturing Data Portfolio
Portafolio de aprendizaje y proyectos enfocados en Data Analytics y Data Engineering, aplicado principalmente a manufactura, operaciones, costos y mejora de procesos.

## Sobre mí
Soy Ingeniero Industrial con experiencia profesional en manufactura, control de costos, presupuestos, análisis de consumo de materiales, KPIs, mejora continua y calidad.
Actualmente estoy desarrollando habilidades técnicas en análisis e ingeniería de datos para avanzar hacia posiciones como:
- Data Analyst
- BI Analyst
- Operations Data Analyst
- Analytics Engineer
- Junior Data Engineer
- Data Engineer
- Data Product Owner
